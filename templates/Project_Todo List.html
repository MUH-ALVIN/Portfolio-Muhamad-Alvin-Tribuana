📝 Aplikasi Manajemen Tugas Modern

Aplikasi berbasis web yang dirancang untuk membantu pengguna mengelola dan memantau tugas sehari-hari dengan lebih terorganisir. Aplikasi ini menyediakan fitur tambah, edit, dan hapus tugas, pencarian, filter berdasarkan status, kategori, prioritas, deadline, progress penyelesaian, serta mode gelap. Data tugas disimpan menggunakan LocalStorage sehingga tetap tersedia setelah halaman dimuat ulang.

Fitur:


  • ➕ Tambah Tugas

    Menambahkan tugas baru dengan nama tugas, deadline, kategori, dan prioritas.


  • ✏️ Edit Tugas

    Mengubah informasi tugas yang sudah dibuat.


  • 🗑️ Hapus Tugas

    Menghapus tugas yang sudah tidak diperlukan.


  • ☑️ Tandai Tugas Selesai

    Menandai tugas sebagai selesai atau belum selesai.


  • 🔍 Pencarian Tugas

    Mencari tugas berdasarkan nama tugas.


  • 🔃 Filter Tugas

    Menampilkan Semua, Belum, atau Selesai.


  • 📅 Deadline Tugas

    Menentukan batas waktu untuk setiap tugas.


  • 🏷️ Kategori Tugas

    Mengelompokkan tugas menjadi Kuliah, Kerja, dan Pribadi.


  • ⭐ Prioritas Tugas

    Menentukan tingkat prioritas Tinggi, Sedang, dan Rendah.


  • 📊 Progress Penyelesaian

    Menampilkan persentase tugas yang telah diselesaikan.


  • 📈 Statistik Tugas

    Menampilkan jumlah Total, Selesai, dan Belum.


  • 🔢 Pengurutan Berdasarkan Deadline

    Mengurutkan tugas berdasarkan tanggal deadline.


  • 🌙 Mode Gelap

    Mengubah tampilan aplikasi ke mode gelap dan menyimpan pilihan tema.


  • 💾 LocalStorage

    Menyimpan data tugas di browser agar tetap tersedia setelah halaman di-refresh.


  • 📱 Desain Responsif

    Desain yang dapat disesuaikan dengan berbagai ukuran layar.
