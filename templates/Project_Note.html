📒 Aplikasi Catatan Digital Modern


Modern Notes App adalah aplikasi catatan berbasis web yang dirancang untuk membantu pengguna membuat dan mengelola catatan secara praktis. Pengguna dapat menambahkan, mengedit, menghapus, mencari, serta menyematkan (pin) catatan penting. Aplikasi ini menggunakan LocalStorage sehingga data catatan tetap tersimpan di browser meskipun halaman di-refresh. Selain itu, tersedia fitur Dark Mode, statistik jumlah catatan, modal untuk mengedit catatan, serta desain responsive yang dapat digunakan pada perangkat desktop maupun mobile.

Fitur:


  • 📝 Menambahkan catatan

    Membuat dan menyimpan catatan baru dengan judul dan isi.


  • ✏️ Edit Catatan

    Mengubah judul atau isi catatan yang sudah dibuat.


  • 🗑️ Hapus Catatan

    Menghapus catatan yang sudah tidak diperlukan.


  • 📌 Pin / Unpin Catatan

    Menyematkan atau melepaskan catatan penting agar tetap terlihat di bagian atas.


  • 🔍 Pencarian Catatan

    Mencari catatan berdasarkan judul atau isi secara cepat.


  • 💾 LocalStorage

    Menyimpan data catatan di browser agar tetap tersedia setelah halaman di-refresh.


  • 🌙 Dark Mode

    Mode gelap untuk kenyamanan pengguna saat bekerja di lingkungan dengan cahaya rendah.


  • 📊 Statistik jumlah catatan

    Menampilkan jumlah seluruh catatan dan catatan yang sedang di-pin.


  • 📱 Desain Responsive

    Menyesuaikan tampilan aplikasi pada desktop, tablet, maupun perangkat mobile.


  • ✨ Modal Edit

    Menampilkan form edit dalam jendela modal dengan animasi saat dibuka untuk memberikan pengalaman interaksi yang lebih nyaman.
