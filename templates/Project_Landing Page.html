🌐 Project Improve — Aplikasi Web Pengembangan Diri


Project Improve adalah aplikasi web yang dirancang untuk membantu pengguna membangun kebiasaan positif dan memantau perkembangan diri secara konsisten. Aplikasi ini menyediakan fitur Habit Tracker untuk mencatat dan menyelesaikan kebiasaan harian, Progress dan Streak untuk memantau konsistensi, Daily Journal untuk mencatat aktivitas atau refleksi harian, serta Dashboard untuk melihat perkembangan pengguna.

Fitur:


  • 📊 Dashboard perkembangan

    Menampilkan ringkasan statistik dan perkembangan kebiasaan pengguna.


  • ✅ Habit Tracker

    Membantu pengguna mencatat dan memantau kebiasaan yang ingin dilakukan setiap hari.


  • 📈 Progress dan Streak

    Menampilkan persentase perkembangan serta jumlah hari pengguna konsisten menjalankan kebiasaan.


  • 📅 Riwayat aktivitas

    Menampilkan catatan aktivitas dan perkembangan yang telah dilakukan pengguna.


  • 📝 Daily Journal

    Memungkinkan pengguna menulis catatan atau refleksi mengenai aktivitas dan pengalaman sehari-hari.


  • 😊 Mood Tracker

    Membantu pengguna mencatat suasana hati setiap hari dan melihat riwayat mood.


  • ⏱️ Pomodoro

    Membantu pengguna mengatur waktu fokus dan istirahat menggunakan timer Pomodoro.


  • 🏆 Achievement

    Memberikan pencapaian berdasarkan konsistensi, progress, dan jumlah habit yang berhasil diselesaikan.
