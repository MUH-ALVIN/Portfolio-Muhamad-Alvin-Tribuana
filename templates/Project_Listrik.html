⚡ Website Pembayaran Listrik Pascabayar


Aplikasi web untuk membantu pelanggan melakukan pengecekan dan pembayaran tagihan listrik pascabayar secara digital. Aplikasi ini dilengkapi dengan sistem login, pengecekan tagihan berdasarkan ID pelanggan, proses pembayaran, serta pengelolaan data pelanggan dan tarif listrik melalui dashboard admin. Aplikasi dikembangkan menggunakan Python, Flask, MySQL, dan Bootstrap dengan sistem yang terintegrasi antara frontend, backend, dan database.

Fitur:


  • 🔐 Login Pengguna

    Sistem autentikasi untuk mengakses layanan aplikasi.


  • 🔎 Cek Tagihan Listrik

    Pelanggan dapat mengecek tagihan menggunakan ID pelanggan.


  • ✅ Status Pembayaran

    Status tagihan akan diperbarui menjadi LUNAS setelah pembayaran berhasil.


  • 👤 Manajemen Pelanggan

    Admin dapat menambah, melihat, mengubah, dan menghapus data pelanggan.


  • ⚡ Manajemen Tarif Listrik

    Admin dapat mengelola data tarif listrik yang digunakan dalam perhitungan tagihan.


  • 📊 Dashboard Admin

    Menyediakan halaman pengelolaan data pelanggan, tarif, tagihan, dan pembayaran.


  • 🧾 Pengecekan Tagihan Sebelum Pembayaran

    Pelanggan dapat melihat detail tagihan sebelum melakukan pembayaran.
